# 源码发布整理 · 2026-10-18

本发布副本只包含 galgame-framework。原有工作目录与 ATRI 私人适配工程未修改。

## 包含内容

- C 引擎与头文件：剧情、图形、动画、音频、存档。
- JSON schema、转换工具、Windows 构建和测试入口。
- 18 节点中文示例、9 张原创几何背景、1 张机器人占位立绘、2 张标题背景和按钮图集。
- 固定测试 fixture、完整开发指南、快速开始、贡献与依赖来源说明。
- .gitignore 与 .gitattributes，便于创建干净仓库。

2026-10-19 补充：新增面向 AI 的 AGENTS.md；完善用户 README 的 AI 请求模板、独立素材包安装、完整性验证与常见问题说明。原作配置与已转换素材另外整理为 atri-material-pack.zip，不写入本源码目录或源码压缩包。

## 未包含内容

可视化编辑器；商业游戏原文件、原作剧情、图片与音频；其转换结果及 ROM；本机 Python/devkitPro/mGBA 二进制；字体、BIOS；旧 Git 元数据、备份、存档、缓存、编译产物和测试日志。

无个人用户名或用户目录硬编码。C:/devkitPro 与 C:/Windows/Fonts/simsun.ttc 是可由环境变量覆盖的 Windows 默认值。完整构建与测试仍需要使用者安装工具链、字体和模拟器。
